## 🎯 Overview

**NovaFlow AI** is a comprehensive, desktop-based loan management platform that leverages Amazon Nova foundation models on AWS to transform how financial institutions originate, document, trade, and manage loans. Built for the Amazon Nova AI Hackathon, this solution demonstrates the power of Amazon Nova across multiple focus areas:

1. **Agentic AI** - Nova-powered agents tackle complex loan analysis, risk assessment, and compliance checking
2. **Multimodal Understanding** - Rich document processing across text, PDFs, and structured data using Amazon Nova
3. **Freestyle** - End-to-end AI-powered loan management and trading platform built on Amazon Nova foundation models

### 🎯 Value Proposition

- **80% reduction** in loan document processing time
- **95% accuracy** in automated data extraction
- **Real-time** covenant breach prediction and risk assessment
- **Transparent** secondary market pricing and trading
- **Full LMA compliance** checking and gap analysis

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn
- Modern web browser (Chrome, Firefox, Edge)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/loanflow-ai.git
cd loanflow-ai
```

2. **Install dependencies**
```bash
npm install
```

3. **Start the development server**
```bash
npm run dev
```

4. **Open in browser**
Navigate to `http://localhost:5173`

### Quick Demo

1. Click **"Load Demo Data"** to populate with sample loans
2. Explore the **Portfolio** tab to see loan cards
3. Click **"Upload Document"** to analyze a loan document with AI
4. Navigate to **Trading** to see the secondary market
5. Check **Analytics** for predictive insights
6. Try **Stress Test** to simulate economic scenarios
7. Review **Market Intelligence** for industry trends
8. Verify **Compliance** with LMA standards
9. Assess **ESG** scores and green lending exposure
10. Use **Export** to generate stakeholder reports

```javascript
Risk Score = (Credit Risk + Market Risk + Operational Risk + ESG Risk) / 4

Levels:
```
